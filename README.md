# رابطة مدرسة سكر سنار النموذجية

حزمة الواجهة العامة ولوحة إدارة المنشورات، بتصميم كحلي وذهبي ومتجاوب مع الهواتف.

## الملفات
- `index.html`: الصفحة الرئيسية وأقسام التعريف والرؤية والأهداف والمنشورات والتواصل.
- `style.css`: الهوية البصرية والتنسيق المتجاوب ولوحة الإدارة.
- `app.js`: تحميل المنشورات ومشاركة الروابط وعدّ المشاهدات.
- `admin.html` و`admin.js`: لوحة دخول المشرفين ونشر المنشورات ورفع الصور.
- `config.js`: إعدادات الاتصال العامة بمشروع Supabase الحالي.

## النشر
ارفع ملفات الحزمة السبعة إلى جذر فرع `association-migration-2026-11-20` في مستودع `sukar-sennar-school`. لا ترفع مجلد الحزمة نفسه؛ ارفع الملفات الموجودة داخله مباشرةً. لا تدمج الفرع في `main` قبل مراجعة النتيجة.

الموقع Static Site ولا يحتاج إلى أمر بناء؛ مجلد النشر هو جذر المستودع (`.`). لا تغيّر إعدادات خدمة الاستضافة القائمة.

## قاعدة البيانات والأمان
- هذه الحزمة تستخدم مشروع Supabase الحالي وإعداداته المنشورة.
- لا تنفّذ ملف SQL جديداً ولا تعِد إنشاء الجداول أو الدوال أو السياسات.
- `config.js` يحتوي عنوان المشروع ومفتاح publishable العام فقط؛ لا تضع أي مفتاح `secret` أو `service_role` في ملفات الواجهة.
- يحافظ عداد المشاهدات على RPC باسم `record_post_view` ومعرّف الزائر `sukar_visitor_id` في `localStorage`.

## الصور
الشعار وصورة المدرسة يُحمّلان من ملفات عامة مثبتة على نسخة المصدر ذات المعرّف `5092ab20a64b64339e44e44df9dec52d908aeaf6`، لذلك لا يلزم رفع الصور ضمن هذه الحزمة.

## ملاحظات المحتوى
الأهداف الواردة تطلعات مستقبلية، ولا تفيد بأن الرابطة نفّذت أنشطة بالفعل. لا تعرض الصفحة أسماء قيادة الرابطة.
