# نحو التحول الرقمي لمدرسة سكر سنار النموذجية

نسخة عامة تعريفية تجريبية (Static Site) باللغة العربية وبتخطيط RTL.

## التشغيل محلياً
افتح `index.html` مباشرة في متصفح حديث.

## النشر على Render
- أنشئ مستودع GitHub وارفع محتويات هذا المجلد.
- في Render اختر New → Static Site واربط المستودع.
- Build Command: اتركه فارغاً.
- Publish Directory: `.`

## قبل الإطلاق العام
- أضف رابط مجموعة واتساب المعتمد في قسم المشاركة.
- أضف رابط صفحة فيسبوك الرسمية.
- فعّل قناة استقبال المقترحات (مثلاً نموذج مرتبط بخدمة استقبال موثوقة).
- راجع الاسم والوصف والجهة المسؤولة مع ممثلي الرابط وإدارة المدرسة.
- لا تضف أرقاماً أو معلومات رسمية غير معتمدة.

## ملاحظة
نموذج التواصل غير مفعّل في هذه النسخة؛ لا توجد قاعدة بيانات أو خدمة خلفية. أُبقيت روابط التواصل كعناصر توضيحية إلى حين توفير الروابط المعتمدة.
